A estrutura de todo programa Arduino

  • Declarações globais: pinos, constantes e variáveis usadas no programa inteiro.
  • setup() roda uma única vez, ao ligar ou depois do reset: configura pinos e comunicação.
  • loop() se repete para sempre, enquanto houver energia.
  • Toda instrução termina com ; e os blocos ficam entre { }.
  • // inicia um comentário: o compilador ignora, mas quem lê o código agradece.

Variáveis e constantes

tipo nome = valor;ex.: int contador = 0;
  • Variável: espaço na memória SRAM cujo valor muda durante o programa.
  • Constante (const): valor fixo; o compilador impede alterações por engano.
  • Global: declarada fora das funções, vale em todo o programa.
  • Local: declarada dentro de uma função, só existe ali.
  • Nomes: letras, números e _, sem acento e sem começar por número. Maiúsculas e minúsculas são diferentes.

No Uno, double é igual a float (4 bytes). Em placas de 32 bits, como o ESP32, int ocupa 4 bytes.

Escolher o tipo errado dá resultado errado

Estouro (overflow)

Quando o valor passa do limite do tipo, ele dá a volta, como um hodômetro: byte 255 + 1 vira 0 e int 32 767 + 1 vira −32 768.

Divisão inteira

Entre inteiros, a divisão descarta a parte decimal: 7 / 2 dá 3. Com um float na conta, 7 / 2.0 dá 3.5.

Conversão (cast)

(float)a / b converte antes de dividir. int x = 3.9; guarda 3: a parte decimal é cortada, não arredondada.

Precedência

Primeiro ( ), depois * / % e por último + -.

2 + 3 * 4 → 14  ·  (2 + 3) * 4 → 20

O resto (%) é muito usado: n % 2 == 0 testa se é par e (n + 1) % 16 faz um contador voltar a zero depois de 15.

Expressões relacionais: comparar valores

OperadorPergunta17 ? 5

O resultado é sempre um bool: verdadeiro (1) ou falso (0). É a base das decisões do próximo encontro.

Erro clássico: = no lugar de ==

x = 5 atribui 5 a x.

x == 5 pergunta se x vale 5.

if (x = 5) compila, muda o valor de x e é sempre verdadeiro.

Expressões binárias: operar bit a bit

OperadorNomeExemplo com 8 bits
&E bit a bit0b1100 & 0b1010 → 0b1000
|OU bit a bit0b1100 | 0b1010 → 0b1110
^OU exclusivo0b1100 ^ 0b1010 → 0b0110
~Inversão~0b00001111 → 0b11110000
<<Desloca à esquerda1 << 3 → 0b1000 (= 8)
>>Desloca à direita0b1000 >> 2 → 0b0010

Bases numéricas

Decimal 13 = binário 0b1101 = hexadecimal 0xD. É o mesmo número escrito de três jeitos.

Ler um bit

(n >> 2) & 1 ou bitRead(n, 2) devolvem o bit 2 de n.

Não confunda

&& e || são lógicos (verdadeiro/falso). & e | operam cada bit.

{{CHIP}}

Experimente: clique nos bits de A e B

Máscaras: & com 1 mantém o bit, com 0 apaga. | com 1 liga o bit. ^ com 1 inverte. É assim que se configuram os registradores do microcontrolador.

Cada pino fornece no máximo 20 mA com segurança (40 mA é o limite absoluto). Por isso o LED sempre leva um resistor em série: 220 Ω a 330 Ω.
