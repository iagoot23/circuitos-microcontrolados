# Circuitos Microcontrolados

Material da unidade curricular do curso Técnico em Automação do SENAI.
Instrutor: Iago Teixeira.

**Apresentação:** https://iagoot23.github.io/circuitos-microcontrolados/

## Conteúdo

- `apresentacao/`: slides em HTML. A fonte fica em `src/`; para gerar o arquivo final, execute `python3 apresentacao/build.py`.
- `info-unidade-curricular.txt`: dados da unidade curricular.

Navegação nos slides: setas do teclado, botões do rodapé ou tecla `M` para o mapa de dias. Os códigos de cada simulação têm o botão **Copiar código**, para colar no Tinkercad ou na Arduino IDE.
